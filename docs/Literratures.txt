Title: Robust color object tracking method against illumination color Change
Abstract:
Color information is one of the most important keys in object tracking. Color appearance of objects depends on illumination color. Therefore, object tracking by color information does not work well in environments with illumination color changes. In some computer vision algorithms, illumination changes are compensated by brightness correction. However, the compensation is insufficient for tracking in recent indoor environments with some types of fluorescent lights and LEDs. The color changes by illumination should be considered in color object tracking. This paper presents an object tracking method based on the gray world assumption (GWA) that relates to the color constancy in human vision. The average color in the vision is regarded as neutral gray in the GWA. In this method, the object color is defined as relative values from the average color in the frame of the image sequence, based on the GWA. Particle filter is used for robust tracking against sudden situation changes. We applied the proposed method to person tracking. Several experiments were examined for evaluation of the proposed method. The experimental results showed good feasibility of the proposed method.

Title: A Multi-Object Tracking Method Using IoU and Color Fusion Model
Abstract:
Multi-object tracking in the complex scenario is challenging. The scenarios such as occlusion and intersection often increase tracking errors like ID switches. To solve these problems, the paper presents a multi-object tracking method using intersection over union (IoU) and color fusion model. First, objects in the input video frames are detected with YOLOX algorithm, and then the object detections with rectangular regions are generated. Second, the Kalman filtering are utilized to estimate the predicted object rectangular regions. Afterwards, we famulate H component histogram based color feature to represent object information. The color features of object rectangular regions are used to calculate the color feature similarity matrix between the detected and predicted objects. A fusion model is established by weighted adding the IoU similarity matrix to the color feature similarity matrix. Finally, we design and implement a two-stage association multi-object tracking framework using the proposed fusion model. Experiments conducted on MOTchal-lenge datasets show that our method achieves Multiple Object Tracking Accuracy (MOTA) scores of 80.6 in MOT17 and 77.9 in MOT20, respectively. Until submission, our method ranks 1st among all the MOT17 and MOT20 trackers.
